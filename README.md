# PhishGuard AI — Final Year Project

AI-Powered Phishing Detection System built with React 19 + TypeScript + Vite + Tailwind CSS.

## Pages Included
- Landing Page (public)
- Login + Register (auth)
- Dashboard Overview
- URL Scanner
- Email Scanner
- Website Scanner
- Threat Intelligence
- Reports
- User Profile
- Settings
- Admin Panel
- Browser Extension Popup

## Quick Start
```bash
npm install
npm run dev        # http://localhost:3000
```
